Satellite basemap — Bengaluru heat digital twin

Real NASA / Esri imagery under the same grid, ward and risk data as the main twin.

Run this file locally or on your own server — it will not load inside claude.ai's published-artifact preview. That sandbox only permits scripts from a handful of whitelisted CDNs and blocks every other network request, including the map tiles this page needs from NASA and Esri. Leaflet itself loads from cdnjs.cloudflare.com (allowed); the imagery tiles come from gibs.earthdata.nasa.gov and server.arcgisonline.com (blocked there). Double-click this file, or serve it with python3 -m http.server and open it in a normal browser tab, and every tile below is a real satellite image.
